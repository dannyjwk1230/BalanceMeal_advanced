# BalanceMeal

모바일소프트웨어 프로젝트 · **정연호 · 최서윤**

## 앱 소개

BalanceMeal은 음식과 섭취량을 기록하고 탄수화물·단백질·지방 및 칼로리를 확인하는 Android 기반 식단 관리 애플리케이션이다. 저장된 신체 정보를 바탕으로 당일 섭취량과 하루 참고 목표의 비교 기능을 제공한다.

- **홈:** 당일 저장된 식단의 영양 합계, 권장 범위, 부족·적정·과다 상태 및 영양 피드백을 표시한다.
- **기록:** 날짜·끼니 선택, 음식 검색·추가·삭제, g/ml 단위 섭취량 입력, 갤러리·카메라 사진 첨부, 식단 저장·변경·삭제 기능을 제공한다.
- **마이:** 프로필 사진 변경 및 닉네임과의 일괄 저장 기능을 제공한다. 생년월일·성별·키·체중·활동 수준 및 목표 계산 적용 여부를 설정한다.
- **목록·분석:** 화면 및 상태·이벤트 구조가 구현되어 있다. **실제 기간 조회, 목록 펼침·상세 이동, 기간별 영양 집계 및 목표 비교는 미연결 상태이다.**

단일 로컬 계정 기반으로 동작하며 로그인, 서버 및 API 키를 요구하지 않는다. 식단은 Room, 프로필·신체 정보는 DataStore, 사진은 앱 내부 저장소에 보관한다.

**기술:** Kotlin · Jetpack Compose / Material 3 · ViewModel / StateFlow · Navigation Compose · Room · Preferences DataStore

## 설치 및 실행 방법

### 준비 환경

| 항목 | 프로젝트 설정 |
| --- | --- |
| Android Studio | AGP 9.5.1 프로젝트를 지원하는 버전 |
| Android SDK | Android API 37 플랫폼 및 SDK Platform-Tools |
| 실행 기기 | Android 7.0(API 24) 이상 실기기 또는 에뮬레이터 |
| Gradle Daemon JDK | 25 (`gradle/gradle-daemon-jvm.properties` 기준) |
| 빌드 도구 | Gradle Wrapper 9.6.0 · AGP 9.5.1 |
| Kotlin / Compose BOM | 2.2.10 / 2026.02.01 |

최초 빌드 시 Gradle 및 의존성 다운로드를 위한 인터넷 연결이 필요하다. 앱 실행은 서버 연결 없이 가능하다.

### Android Studio에서 실행

1. 저장소를 복제한다.
   ```bash
   git clone https://github.com/dannyjwk1230/BalanceMeal_advanced.git
   cd BalanceMeal_advanced
   ```
2. Android Studio에서 `settings.gradle.kts`가 위치한 프로젝트 루트를 연다.
3. SDK Manager에서 API 37을 설치한 후 Gradle Sync를 실행한다. JDK 25가 설치되어 있지 않은 경우 해당 버전을 설치하고 Gradle JDK 설정을 확인한다.
4. SDK 경로 설정에는 Android Studio가 생성한 `local.properties`를 사용한다. 해당 파일은 개발 환경별 경로를 포함하므로 Git 관리 대상에서 제외한다.
5. 에뮬레이터 또는 USB 디버깅이 활성화된 기기를 선택한 후 실행 구성 **app → Run**을 실행한다.

### 명령줄에서 빌드·설치

Windows PowerShell 기준 프로젝트 루트에서 다음 명령을 실행한다.

```powershell
.\gradlew.bat :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.example.balancemeal_advanced/.MainActivity
```

macOS/Linux에서는 `./gradlew :app:assembleDebug`를 사용하며, APK 생성 위치는 Windows와 동일하다. `adb`는 SDK의 `platform-tools`에 위치하며, PATH 등록 또는 실행 파일의 전체 경로 지정을 통해 실행한다.

사진 선택 기능은 이미지를 제공하는 갤러리·파일 선택 앱을, 사진 촬영 기능은 카메라 앱을 필요로 한다. 에뮬레이터에서는 이미지 파일 추가 또는 가상 카메라 설정을 통해 해당 기능을 검증한다.

### 간단한 사용 순서

1. **마이**에서 신체 정보를 입력하고 저장한다. 목표 계산의 적용 대상은 만 19세 이상이다.
2. **기록**에서 날짜·끼니를 선택하고 음식을 검색한 후 0보다 큰 섭취량을 입력한다.
3. 식단 저장 후 **홈**에서 당일 섭취 합계와 목표 비교 결과를 확인한다.
4. 기존 날짜·끼니의 기록을 열어 내용을 변경하거나, 모든 음식을 제거한 후 식단을 삭제한다.

앱 삭제 또는 앱 데이터 초기화 시 로컬 기록이 삭제된다. 일반 업데이트에는 `adb install -r`을 사용한다.

### 검증 명령

```powershell
# APK, 단위 테스트, 정적 검사, 기기 테스트 APK 빌드
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest

# 기기를 연결한 상태에서 UI·저장소 테스트 실행
.\gradlew.bat :app:connectedDebugAndroidTest
```

제출 준비 과정의 검증 결과 및 추가 확인 항목은 [통합 인수인계 문서](docs/TEAM_HANDOFF.md#검증과-시연)에 정리되어 있다. 기기 테스트 APK 빌드와 실제 기기 테스트 실행은 별도의 검증 단계이다.

## 영양 데이터 출처

| 구분 | 출처 및 앱 적용 방식 |
| --- | --- |
| 음식 영양 데이터 | **식품의약품안전처**. 공식 안내: [K-FIND 식품영양성분 데이터베이스](https://various.foodsafetykorea.go.kr/nutrient/index.do). 앱은 제공된 100개 음식이 포함된 [foods_sample.json](app/src/main/assets/foods_sample.json)을 사용한다. |
| 하루 참고 목표 | **보건복지부·한국영양학회, 한국인 영양소 섭취기준**을 참고한 프로젝트 명세의 성인 EER·활동 계수·영양소 범위를 적용한다. 공식 자료의 출처는 [한국영양학회 KDRIs 자료실](https://www.kns.or.kr/fileroom/fileroom_view.asp?BoardID=Kdr&idx=167)이다. |

- 음식 데이터는 100g 기준 80개와 100ml 기준 20개로 구성되며, 실시간 외부 API 호출은 사용하지 않는다.
- 영양 성분과 칼로리는 원본의 100g/100ml 값에 `섭취량 ÷ 100`을 곱하여 산출한다. ml의 g 환산 및 탄수화물·단백질·지방에 기반한 칼로리 재계산은 수행하지 않는다.
- 참고 목표의 산출에는 앱에 구현된 계산식과 범위를 사용한다. 적용 범위는 프로젝트 명세에 한정되며, 공식 자료 최신판 전체의 구현을 의미하지 않는다. 데이터 원본에는 개별 항목의 수집일 및 원본 DB 판본 정보가 포함되어 있지 않다.
- 목표와 영양 피드백은 참고용 추정치이다.
